#### Важная информация о сборке: Корпоративный сервер 2024, версия 2026.3.6.17475
В хотфикс-сборке Корпоративный сервер 2024 версии 2026.3.6.17475 реализовано исправление трех серьезных дефектов:

- Модуль Управление: устранена проблема, приводившая к возникновению ошибки («EmptyCustomer») при авторизации пользователя по LDAP;
- Модуль Проекты: Пользователям теперь доступен поиск задачи по ее номеру или по ключу проекта (POKY-274);
- Модуль Календарь: Решена проблема, когда при открытии модального окна накладывалось отображение участников события на заполненное описание события (KLNA-62).
